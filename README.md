# November — Omarchy theme

A cozy dark autumn theme for [Omarchy](https://omarchy.org): espresso backgrounds, warm cream text, pumpkin accent, cranberry, and harvest gold. Seven wallpapers, one for each day of the week.

Art by Arty for John Bracich.

## Install

The repository is the theme assets: `colors.toml`, `icons.theme`, `preview.png`, and `backgrounds/`.

```bash
omarchy theme install https://github.com/JB3AZ/omarchy-november-theme.git
```

Or use **Install → Style → Theme** in the Omarchy menu with that same URL.

Then pick **November** in the theme menu (or run `omarchy-theme-set november`).

Choose a wallpaper from the background menu with Super + Ctrl + Space. The files are ordered Sunday through Saturday.
